# World outline

`world-land.svg` is an equirectangular outline generated from
[world-atlas 2.0.2 / land-110m.json](https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/land-110m.json).
The underlying 1:110m land data comes from [Natural Earth](https://www.naturalearthdata.com/),
whose geographic data is in the public domain. The outline contains no country boundaries.
The SVG is served with this website; displaying it makes no request to a map provider.
